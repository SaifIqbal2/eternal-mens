You no longer need to manually place files here for most categories —
Admin → Categories now has an image upload field when you add or edit
a category, which handles this automatically.

This folder is still where those uploaded files actually get stored,
plus it's used as a fallback: if a category has no uploaded image, the
site looks here for a file named after that category's slug (e.g.
watches.jpg, wallets.jpg) before giving up. The images already here
from before still work exactly as they did.
